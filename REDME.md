# Todo List Web Application

A simple Todo List Web Application built using HTML, CSS, and JavaScript with Local Storage support.

---

# Features

## Current Features

- Add Todo
- Update Todo
- Delete Todo
- Save Todos in Local Storage
- Data remains after page refresh

---
